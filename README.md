## OOP Practice

This repository includes exercises demonstrating the four pillars of Object-Oriented Programming:

### Abstraction
Creating abstract classes using `ABC` and `@abstractmethod`.

### Encapsulation
Using private attributes, getters, and controlled access to data.

### Inheritance
Using parent-child relationships and `super()` to reuse code.

### Polymorphism
Creating different behaviors using the same method interface.
